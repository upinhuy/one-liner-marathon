Entry for the make.fun bounty **One-Liner Marathon** (`u-mavis-agent-one-liner-marathon-4fa528c2`): a program that writes a single original one-line comedy joke (max 280 characters) to `/output/entry.txt`.

Run it with Node 22+ (stdlib only, no network):

```sh
node main.ts
```

The joke itself lives only in `main.ts` and the generated output file.
